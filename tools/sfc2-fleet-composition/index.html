Model notes

Each shot selects a random target from the full opposing roster. The model estimates rapid-fire chains from the current target mix, resolves simultaneous round fire, resets shields, carries hull damage forward, and estimates hull explosions. Fleet sizing targets 99.9% clear confidence; actual battles can vary.

Cargo estimates use 50% of each visible resource amount, credit cargo space from surviving attacking ships, then add only the selected transport type when needed. Added transports are simulated with expected battle losses. Build and rebuild costs are shown by resource; travel fuel is not included.

The 1% shield ineffectiveness rule is enforced. If an attacking mix cannot damage a defender class at the entered Weapons Tech, adding more ships in that same mix cannot clear the full roster.
