Ship Build Time

Estimate the total shipyard time for huge orders, then copy the exact ship count without commas or an extra zero.

How to use: Choose a ship, enter its count (for example, 1 septillion or 1Sp), then set the Shipyard and Foundry levels and the number of Build Droids assigned to that Shipyard. The grouped count and magnitude label let you check the value before copying the digits-only string.
